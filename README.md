# SINANA Sales

Самостоятельное приложение для руководителя и торговых представителей SINANA. Проект не использует код, базу данных, пользователей или настройки WMS.

Реализованы роли и пароли, сотрудники, торговые точки, GPS-маршруты и контроль местоположения, фотоматериалы, заказы, выбранная группа номенклатуры 1С, контрагенты, склады и остатки, типы цен, возвраты, рецептуры, расчёт себестоимости и производственные задания для пищевого и кондитерского производства.

## Локальный запуск

1. Создайте виртуальное окружение и установите `requirements.txt`.
2. Установите переменные `SINANA_SECRET_KEY`, `SINANA_ADMIN_LOGIN`, `SINANA_ADMIN_PASSWORD`.
3. Выполните `flask --app run.py init-admin`.
4. Запустите `flask --app run.py run`.

Для сервера база задаётся отдельной переменной `SINANA_DATABASE_URL`; рекомендуется отдельная PostgreSQL-база и отдельный домен.

## Сервер

Скопируйте `.env.example` в `.env`, задайте отдельные пароли и запустите `docker compose up -d --build`. После первого запуска создайте руководителя командой `docker compose exec app flask --app run.py init-admin`. Приложение слушает только `127.0.0.1:8001`; внешний HTTPS настраивается через Nginx. Формат обмена с 1С описан в `docs/1c-integration.md`.
